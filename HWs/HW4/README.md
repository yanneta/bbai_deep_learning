# HW4: Recommender System with Implicit Feedback

In this assignment you will build recommender systems on implicit feedback data (clicks, views, likes) using a subset of the Tenrec (Tencent) dataset. The homework has two parts; complete them in order, since Part 2 reuses the artifacts you produce in Part 1.

| Part | Topic | Instructions |
|------|-------|--------------|
| 1 | Building a baseline recommender system (popularity and item–item similarity) | [Part 1](part1.md) |
| 2 | Building a personalized model with implicit feedback (negative sampling and matrix factorization) | [Part 2](part2.md) |
